## RIPPS2 builds 155 and 156 (not released, not lab-run)
- **155:** BIBLE a060790 inside; the one-folder install on in every build; f5705eb known as older.
- **156, your MMCE `.wav`:** the music file reached the card as back-to-back requests, each holding the SIO2 bus for the
  SD time, while audsrv keeps only about 107 ms queued on the IOP. Ogg needs a piece every ~13 s; a CD `.wav` (176 KB/s)
  every 1.4 s. Now: unbuffered, 32 KB requests, 16 KB with a 2 ms gap on MMCE (the covers' build 115 pacing).
  **Format answer:** keep `.wav` for rips. For music that lives on the MMCE, a 44.1 kHz stereo `.ogg` (about 20 KB/s) is
  the safe format. One run with STATUS > SAVE DIAGNOSTICS after playing a `.wav` puts `music read ... KB/s` lines in
  DIAG.TXT, which say whether the card keeps up.
- **156, the exit glitch:** RIPDISC's hand-off into Memory Files left the bar on LAUNCH DISC; backing out showed the orbs
  (START BROWSER, the ORBIT names) under it. The bar now moves to MEMORY FILES with the browser.
- **156:** "Circle: stop" and the sound preview's words are button glyphs now.
- Not done: a lab run; a console run on the SD2PSX for the `.wav`.
